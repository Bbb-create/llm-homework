# 人工智能导论期末作业：班级成绩统计分析系统
## 项目简介
基于原生Python实现班级成绩自动化统计，自动计算最高分、最低分、平均分，划分成绩等级，实现基础数据智能化处理，无第三方库依赖，运行稳定无环境报错。

## 运行环境
任意已安装Python3的电脑，无需额外pip/conda安装依赖包

## 一键运行命令
python score_analysis.py

## 项目文件说明
score_analysis.py   项目主程序源代码
report.md            完整项目作业报告文档
requirements.txt     依赖说明文件
README.md            项目说明文档
